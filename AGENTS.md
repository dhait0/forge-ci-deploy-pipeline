# Mission

Build a bilingual Jenkins, Docker, and Linux CI/CD demo that looks like a production deployment pipeline, not a tutorial.

## Product rules

- Focus on CI/CD operations, Linux runner checks, Docker builds, smoke tests, and rollback behavior.
- Use only demo service metadata and fake release versions.
- Keep English and Spanish context in README, docs, and service responses.
- Do not include real credentials, private registry URLs, customer names, or internal deployment logic.
- Keep the visual identity distinct from dashboard, API, and backend demos.

## Repository standards

- Include `README.md`, `docs/`, `LICENSE`, `.env.example`, `.gitignore`, and screenshots.
- Keep TypeScript strict mode enabled.
- Document architecture, implementation, decisions, and future improvements.
